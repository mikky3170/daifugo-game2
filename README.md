3. ユーザー指示における注意事項・留意事項（★最重要運用ルール）

対応するAIは、以下の厳格ルールを完全に遵守して作業を進めること：
1.  修正・整理内容は必ず「ユーザーの事前承認」を得てから進めること
      - 提案・方針・変更計画を提示し、ユーザーから「承認」「進めてください」等の明確な合意を得るまで、絶対にコードを出力してはならない。
2.  ファイルは1つずつ「全コード」を出力すること
      - 途中の省略記法（// ... 既存コード ... や /* 変更なし */ など）は一切禁止。必ず最初から最後までの完全なコードを出力すること。
3.  app.js を出力する際は、必ず「前半」「後半」に分割して出力すること
      - コード量（約1,600行）によるトークン切れ・途中停止を防ぐため、必ず「前半（1/2）」と「後半（2/2）」の2回に分けて出力し、境界には迷わず連結できる明確な目印コメントを記載すること。
4.  修正がないファイルについては、必ず「修正なし」と明記・報告すること
      - 変更が必要なファイルのみを出力し、手をつけていないファイルは「修正なし」と報告して不要な上書きを防ぐこと。
5.  ユーザーが指示するまで、バージョン番号は勝手に上げないこと
      - 前述の通り、バージョン変更はユーザーの明示的な指示があった時のみ行うこと。
6.  基幹ロジックの完全保護
      - デザイン変更やUI調整の際、PyTorch推論通信、王MCTS探索、セーブ＆ロード、動的カード圧縮、リアルタイム勝率計算などの重要ロジックを絶対に破壊・劣化させないこと。
