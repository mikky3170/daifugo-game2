大富豪王2026のAI学習強化のレイアウト刷新版です。
最新バージョン v2.5.3 で実装・反映した改修内容は以下の通りです。 主に画面全体の美観・バランスの最適化と、パーツのはみ出し・揺れ防止の徹底を行いました。

👑 v2.5.3 改修内容まとめ
1. キャラクター情報・役職バッジの端正な整列
  - CPU2（上部）: キャラクター名と「大富豪」などの役職バッジの横幅を完全一致させ、ピシッと揃った2段レイアウトに統一。
  - CPU1（左）＆ CPU3（右）: キャラクター名の直下に役職バッジを配置し、キャラ名と幅を完全一致（同幅）に統一。
2. セリフ枠・絵柄拡大の品格向上
  - CPU1のセリフ枠: 改行をなくし（1行表示）、セリフ枠から文字が絶対に突き破らないようパディングと幅を適正化。
  - CPU絵柄（肖像画）拡大の改善:
      - 元の絵柄の上側からはみ出さないよう、拡大の基準点を上端に固定（transform-origin: top center）。
      - 従来の1.35倍から 1.5倍（ひと回り大きく） へ拡大率を引き上げ、発言時に下方向へ優雅に広がるリッチな演出へ刷新。
3. 演出バナーの中央祭壇内完全収容
  - 革命・11バック・8切りバナー:
    迫力はそのままに、中央祭壇（金枠）の外側へ突き出さないコンパクトな宮廷シネマティック枠（最大幅250px以内）へ微調整。
4. フォント＆ボタンデザインの宮廷化
  - ボタン文字の明朝体統一: 下部操作ボタン、モーダル内ボタン、BGMボタンなど、全ボタンのフォントを気品ある Cinzel ＋ Noto Serif
    JP（高級宮廷明朝体） に完全統一。
  - WINNERポップアップ: 1位ゴール時の「大富豪」や名前の表示フォントサイズを 1.5倍に拡大 し、劇的な勝利感を強化。
5. 操作ボタンの配置整理＆名称変更
  - 自動ボタン: 操作バーの左端へ美しく整列。
  - 戦績ボタン: 「戦績」から 「📊 戦績表示」 へ名称変更。
  - キャラ抽選ボタン: リセットボタンの名称を 「🔄 キャラ抽選」 に変更し、操作バーの一番右端へ独立配置（誤タップ防止）。
6. 枠サイズの完全固定（ガタつき防止）
  - 「AI稼働中」プレート: 「AI: 稼働中」「AI: 推論中...」「AI:
    待機中」と状態テキストが変わっても、枠の横幅（92px）・高さ（26px）が1ピクセルも伸縮・揺れ動かないよう完全固定化。
7. バージョン履歴モーダルの見やすさ向上
  - 金枠カード化: 各バージョン（v2.5.3,
    v2.5.2…）ごとに独立したエレガントな金枠カード（.version-card）で囲み、更新内容の視認性を向上。
8. スマートフォン縦画面のレスポンシブ最適化
  - 中央祭壇＆トランプの縮小: スマホ時の中央祭壇の横幅を少し短くし、内部のトランプカードもバランス良く縮小。
  - 左右CPUカード束の重なり調整: CPU1・CPU3のカード裏面の重なりを少し深くし、画面の左右両サイドからはみ出さないスリムな束感へ調整。
