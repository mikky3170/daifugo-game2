# daifugo-game2
大富豪王2026のAI学習強化のレイアウト刷新版です。
最新バージョン v2.5.3 で実装・反映した改修内容は以下の通りです。 主に画面全体の美観・バランスの最適化と、パーツのはみ出し・揺れ防止の徹底を行いました。

👑 v2.5.7 改修内容まとめ

1.ゲームのセーブ＆ロード機能の新規実装
　下部操作バーに「💾 セーブ」「📂 ロード」ボタンを新設。
　手札、場のカード、ターン、パス回数、革命状態、役職、キャラクター割り当てなど対戦の全状態を　　LocalStorageへ即時保存＆1タップで完全復元できる設計を構築。
2.カード交換ボタンの完全センタリング
　「カード交換へ」「交換決定」ボタン内のテキストを display: flex; justify-content: center; align-items: center; で完全中央配置に。
3.ゲーム画面のキャラ名幅拡張（大富豪でも改行ゼロ）
キャラ名バッジおよび役職バッジの幅を 88px に拡張し、white-space: nowrap で「大富豪」「超級AI」等が付いても絶対に改行しない構造へ。
4.キャラ選択画面の点滅エフェクト（選択促進＆タイトル優美点滅）
タイトルロゴの周りにゆっくりと黄金の光彩が呼吸するように灯る royalTitleGlow アニメーションを搭載。
キャラクターカード群にも優しく選択を促すパルス点滅エフェクトを適用。
5.プレイヤー肖像画・キャラ名の位置完全固定（左右ブレ根絶）
「あなたの順番です」バッジの出現・非出現によって左右に1ミリも動かないよう、プレイヤープレート全体の固定幅スロット（肖像画＋情報）を厳格に確立。
「あなたの順番です」バッジのひと回り拡大
フォントサイズとプレート高さをひと回り大きく（clamp(11px, 1.5vh, 13px)）拡大し、手番時の視認性と存在感を向上。
CPUの「残り枚数」と「カード枚数」の完全一致化
これまで上限8枚でカットされていたカード裏面描画を撤廃し、「残り14枚」なら実際のトランプ裏面も14枚きっちり並ぶ完全一致仕様に修正。
自動ボタンON時の選択状態ハイライト
自動プレイがONの時は、鮮やかなシャンパンゴールド＋黄金光彩の「選択中」スタイルへ切り替わり、一目でONとわかるデザインに刷新。
ジョーカー2枚の絵柄・色彩の完全差別化
ジョーカー1（★）: 黄金の仮面（🎭）＋ 百合の紋章透かし（⚜️）＋ 赤金インク
ジョーカー2（☆）: 神秘の道化帽（🎪）＋ 王冠透かし（👑）＋ 銀青色インク
手札に2枚入った際も明確に区別がつくデザインへ。
CPU1・CPU3の「残り枚数」の右に「パス回数」を横並び配置
ご指定通り、左右座席でも「残り ○枚」のすぐ右隣に「パス: ○」を横並び配置。
スマホ時のCPU1・CPU3カード重なりを倍近く深化
重なりマージンを倍近く深く（-28px）設定し、枚数が多くても画面サイドにはみ出さずコンパクトに凝縮。
